# Security Policy

## Reporting a vulnerability

Report security vulnerabilities using GitHub's private vulnerability reporting:
go to the **Security** tab of this repository and select **"Report a
vulnerability."** This opens a private advisory visible only to maintainers,
so details are not disclosed publicly while a fix is prepared.

**Do not open a public issue for a security vulnerability.**

If you cannot use private vulnerability reporting, write to
<support@pay-cross.com> and say that the report is a security issue.

## Supported versions

The latest minor release line receives security fixes. Older lines do not, so
upgrade to the current release before reporting a problem you can still
reproduce.
